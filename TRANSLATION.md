# TRANSLATION NOTES

Please create a fork of this repository and create a Pull Request with your translations instead of creating a different mod.

If you don't know how to do that:

1. Create a fork

![fork](https://github.com/flye-name/terraria-pronouns/blob/717a7fe5321097bbfb567f9dac8ec434a5c36ee4/Demonstrations/Fork.png)

2. Create the localization files on **your fork**
   1. Both the `.hjson` files and the ones without extensions are translated as normal, simply copy the file and replace the en-US prefix in the file name with the new language.
3. Create a pull request in **this repository**

![pr](https://github.com/flye-name/terraria-pronouns/blob/00f8a1b72b27d1dfe7e86f25af7e3e4b77b0ff88/Demonstrations/PR.png)

4. Click **"compare across forks"** if available
5. Review changed files and submit


### Why
Support for other mods' death messages involves replacing their localization entries with ones in this mod, [an example of this.](https://github.com/flye-name/terraria-pronouns/blob/master/Localization/en-US_Calamity)
This means that external translation mods can't do this part, support has to be integrated here.
